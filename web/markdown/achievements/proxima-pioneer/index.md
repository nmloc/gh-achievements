# Proxima Pioneer (GitHub achievement)

- Status: Internal (GitHub staff only)
- How to earn: GitHub staff: contributed to the Proxima proof of concept
- Tiers: one tier
- Progress in gh-achievements: earned or not

Proxima Pioneer is an internal badge for GitHub staff who contributed to the Proxima proof of concept. It cannot be earned through normal activity.

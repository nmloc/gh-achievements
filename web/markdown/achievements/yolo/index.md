# YOLO (GitHub achievement)

- Status: Earnable
- How to earn: Merge a pull request without a review
- Tiers: one tier
- Progress in gh-achievements: earned or not (official)

YOLO ("You want it? You merge it.") is a one-time badge for merging a pull request without a code review.

Check your progress: `gh achievements` or https://gh-achievements.vercel.app/check/

# Proxima Staffshipper (GitHub achievement)

- Status: Internal (GitHub staff only)
- How to earn: GitHub staff: shipped the Proxima staffship instance
- Tiers: one tier
- Progress in gh-achievements: earned or not

Proxima Staffshipper is an internal badge for GitHub staff who shipped the Proxima staffship instance. It cannot be earned through normal activity.

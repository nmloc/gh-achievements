# Mars 2020 Contributor (GitHub achievement)

- Status: Retired (no longer earnable)
- How to earn: Code in a repository used by the Mars 2020 Helicopter Mission
- Tiers: one tier
- Progress in gh-achievements: earned or not

Mars 2020 Contributor went to people who contributed code to repositories used in the Mars 2020 Helicopter Mission. It can no longer be earned.

# Public Sponsor (GitHub achievement)

- Status: Earnable
- How to earn: Sponsor someone publicly through GitHub Sponsors
- Tiers: one tier
- Progress in gh-achievements: earned or not (official)

Public Sponsor is a one-time badge for sponsoring an open source contributor or organization through GitHub Sponsors with a public sponsorship. Private sponsorships do not count.

Check your progress: `gh achievements` or https://gh-achievements.vercel.app/check/

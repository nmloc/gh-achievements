# Finishing Touch (GitHub achievement)

- Status: Earnable
- How to earn: Get pull requests that improve GitHub's UI quality merged
- Tiers: 1 · 4 · 16 · 32
- Progress in gh-achievements: official tier (no public counting rule)

Finishing Touch counts merged pull requests that GitHub classed as improving the quality of its own user interface. GitHub's history for the badge names the 1st, 4th, 16th and 32nd UI quality pull request merged.

| Tier | Needed |
|---|---|
| x1 · base | 1 merged UI quality pull requests |
| x2 · bronze | 4 merged UI quality pull requests |
| x3 · silver | 16 merged UI quality pull requests |
| x4 · gold | 32 merged UI quality pull requests |

## FAQ

### How many pull requests do you need for Finishing Touch?

1 merged UI quality pull request for the base badge, 4 for x2, 16 for x3 and 32 for x4.

Check your progress: `gh achievements` or https://gh-achievements.vercel.app/check/

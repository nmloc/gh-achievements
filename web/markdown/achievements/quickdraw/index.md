# Quickdraw (GitHub achievement)

- Status: Earnable
- How to earn: Close an issue or pull request within 5 minutes of opening it
- Tiers: one tier
- Progress in gh-achievements: earned or not (official)

Quickdraw ("Gitty up!") is a one-time badge for closing an issue or pull request within 5 minutes of opening it.

Check your progress: `gh achievements` or https://gh-achievements.vercel.app/check/

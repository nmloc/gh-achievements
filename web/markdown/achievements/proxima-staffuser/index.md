# Proxima Staffuser (GitHub achievement)

- Status: Internal (GitHub staff only)
- How to earn: GitHub staff: your team was onboarded to Proxima
- Tiers: one tier
- Progress in gh-achievements: earned or not

Proxima Staffuser is an internal badge for GitHub staff whose team was onboarded to Proxima. It cannot be earned through normal activity.

# Arctic Code Vault Contributor (GitHub achievement)

- Status: Retired (no longer earnable)
- How to earn: Code in a repository of the 2020 GitHub Archive Program
- Tiers: one tier
- Progress in gh-achievements: earned or not

Arctic Code Vault Contributor went to people who contributed code to repositories stored in the 2020 GitHub Archive Program. It can no longer be earned.

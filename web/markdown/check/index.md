# Check your GitHub achievements

Type a username at https://gh-achievements.vercel.app/check/ for public data, or sign in with GitHub to include private contributions. A public report has a shareable address: https://gh-achievements.vercel.app/result?u=<username>.

In a terminal: `gh extension install nmloc/gh-achievements`, then `gh achievements [username]` (add `--json` for machine-readable output).

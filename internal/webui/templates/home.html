Needs the GitHub CLI. Add a username to check anyone: gh achievements torvalds.

What it shows

  • Every achievement. All {{.Count}} known badges ({{.Summary}}) and 6 profile highlights, not just the ones you have.
  • Your tier and the next one. A progress bar to the next threshold, e.g. 72 of 128 merged pull requests for Pull Shark x3.
  • Checked against GitHub. Tiers, unlock dates and milestones come from GitHub's own badge history. Pull Shark's count is calibrated against the pull requests GitHub names. How accurate is it?
  • No stored token. The CLI reuses your gh auth login and talks only to GitHub. The web checker signs in with GitHub, uses the token for one check and revokes it.

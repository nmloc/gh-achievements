Public Sponsor

Public Sponsor is a one-time badge for sponsoring an open source contributor or organization through GitHub Sponsors with a public sponsorship. Private sponsorships do not count.

How to earn it
Sponsor someone publicly through GitHub Sponsors
Status
Earnable
Tiers
one tier
Progress in gh achievements
Earned or not (official)

Check your Public Sponsor progress

gh extension install nmloc/gh-achievements
gh achievements

It shows your Public Sponsor tier, when you unlocked it and, where GitHub's data allows, how many more you need for the next tier.

Profile highlights

Highlights appear below the achievements on a profile. They are not tiered.

  • Developer Program Member: Register for the GitHub Developer Program.
  • Security Bug Bounty Hunter: Report a valid vulnerability through GitHub Security Bug Bounty.
  • GitHub Campus Expert: Join the GitHub Campus Expert program.
  • GitHub Star: Be selected for the GitHub Stars program.
  • Pro: Subscribe to GitHub Pro.
  • Security advisory credit: Have a security advisory you submitted accepted into the GitHub Advisory Database.

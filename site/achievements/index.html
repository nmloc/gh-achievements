All GitHub achievements

GitHub publishes no official list of profile achievements any more. These are all the known ones (8 earnable, 2 disabled, 2 retired, 3 internal), with their tier thresholds and whether you can still earn them.

Earnable

You can still earn these.

  • Pull Shark

    Open pull requests that get merged.

    Tiers: 2 · 16 · 128 · 1024

  • Starstruck

    Create a repository that gets stars.

    Tiers: 16 · 128 · 512 · 4096

  • Pair Extraordinaire

    Coauthor commits on merged pull requests.

    Tiers: 1 · 10 · 24 · 48

  • Galaxy Brain

    Have discussion answers accepted.

    Tiers: 2 · 8 · 16 · 32

  • Quickdraw

    Close an issue or pull request within 5 minutes of opening it.

    One tier

  • YOLO

    Merge a pull request without a review.

    One tier

  • Public Sponsor

    Sponsor someone publicly through GitHub Sponsors.

    One tier

  • Finishing Touch

    Get pull requests that improve GitHub's UI quality merged.

    Tiers: 1 · 4 · 16 · 32

Switched off by GitHub

GitHub tested these and switched them off; nobody can earn them now.

  • Heart On Your Sleeve

    React to something on GitHub with a ❤️ emoji.

    Tiers: ? · 16 · 128 · ?

  • Open Sourcerer

    Have pull requests merged in several public repositories.

    Tiers: ? · 8 · 16 · 64

Retired

No longer awarded. Profiles that have them keep them.

  • Arctic Code Vault Contributor

    Code in a repository of the 2020 GitHub Archive Program.

    One tier

  • Mars 2020 Contributor

    Code in a repository used by the Mars 2020 Helicopter Mission.

    One tier

GitHub staff only

Only GitHub staff could earn these.

  • Proxima Pioneer

    GitHub staff: contributed to the Proxima proof of concept.

    One tier

  • Proxima Staffshipper

    GitHub staff: shipped the Proxima staffship instance.

    One tier

  • Proxima Staffuser

    GitHub staff: your team was onboarded to Proxima.

    One tier

Profile highlights

Highlights appear below the achievements on a profile. They are not tiered.

  • Developer Program Member: Register for the GitHub Developer Program.
  • Security Bug Bounty Hunter: Report a valid vulnerability through GitHub Security Bug Bounty.
  • GitHub Campus Expert: Join the GitHub Campus Expert program.
  • GitHub Star: Be selected for the GitHub Stars program.
  • Pro: Subscribe to GitHub Pro.
  • Security advisory credit: Have a security advisory you submitted accepted into the GitHub Advisory Database.

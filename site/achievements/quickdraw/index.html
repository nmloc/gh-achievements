Quickdraw

Quickdraw ("Gitty up!") is a one-time badge for closing an issue or pull request within 5 minutes of opening it.

How to earn it
Close an issue or pull request within 5 minutes of opening it
Status
Earnable
Tiers
one tier
Progress in gh achievements
Earned or not (official)

Check your Quickdraw progress

gh extension install nmloc/gh-achievements
gh achievements

It shows your Quickdraw tier, when you unlocked it and, where GitHub's data allows, how many more you need for the next tier.

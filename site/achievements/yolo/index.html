YOLO

YOLO ("You want it? You merge it.") is a one-time badge for merging a pull request without a code review.

How to earn it
Merge a pull request without a review
Status
Earnable
Tiers
one tier
Progress in gh achievements
Earned or not (official)

Check your YOLO progress

gh extension install nmloc/gh-achievements
gh achievements

It shows your YOLO tier, when you unlocked it and, where GitHub's data allows, how many more you need for the next tier.
